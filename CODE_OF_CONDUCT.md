# Code of Conduct

Tarn follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep
discussions about the work. Harassment and personal attacks are not
tolerated in issues, pull requests, discussions, or any other project space.

To report unacceptable behaviour, contact the maintainer privately through
GitHub ([@cstheorist](https://github.com/cstheorist)). Reports are handled
confidentially, and the maintainer will act as described in the Covenant's
enforcement guidelines.
